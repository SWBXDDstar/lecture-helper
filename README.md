# Lecture Helper

초등 교실에서 쓰려고 만든 **수업용 화면 도구 두 개**입니다.
조작감은 **라이트샷**, 모드 구조와 단축키는 **줌잇**을 따릅니다.

| 프로그램 | 언제 쓰나 | 결과물 |
|---|---|---|
| **ScreenNote** | 수업 *중에*, 말하면서 | 없음. 끄면 사라짐 |
| **ScreenCapture** | 수업 *전후에*, 자료 만들 때 | 파일 / 클립보드 / 고정된 이미지 |

두 프로그램은 **그리기 단축키를 똑같이 씁니다.** 손이 한 번만 익으면 됩니다.

## 설치

1. [.NET 8 데스크톱 런타임](https://dotnet.microsoft.com/download/dotnet/8.0/runtime) 설치 (없을 때만)
2. `dist\ScreenNote.exe`, `dist\ScreenCapture.exe` 를 받아서 원하는 폴더에 두고 실행

**남에게 나눠줄 때는 포터블본**(`dist-portable\LectureHelper_Portable.zip`, 115 MB)을 주세요.
.NET 런타임이 exe 안에 들어 있어 아무것도 설치할 필요가 없습니다. 만드는 법은 아래 「빌드」에 있습니다.

각각 트레이에 상주합니다. 둘 다 켜둬도 단축키가 안 겹칩니다. 수업 때는 ScreenNote만 켜두면 됩니다.

| | ScreenNote | ScreenCapture |
|---|---|---|
| | `Ctrl+1` 확대 | `Ctrl+F1` 캡처 |
| | `Ctrl+2` 화면 주석 | `F3` 클립보드 이미지 고정 |
| | `Ctrl+3` 수업 타이머 | |

Windows 64비트 전용입니다.

## 컴퓨터 켤 때 자동 실행

트레이 아이콘을 오른쪽 클릭 → **"Windows 시작 시 자동 실행"** 을 체크하면 됩니다. 두 프로그램 각각 따로 켜고 끕니다.

내 계정에만 등록되므로 관리자 권한이 필요 없고, 다른 선생님 계정에는 영향이 없습니다.
`dist` 폴더를 다른 곳으로 옮겨도 다음 실행 때 등록 경로가 알아서 새 위치로 갱신됩니다.

## 그리기 단축키 — 두 프로그램이 동일

수업 중에 쓰는 도구와 자료 만들 때 쓰는 도구에서 네모 그리는 키가 다르면 손이 꼬입니다.
그래서 **도형 단축키는 한 벌만 있습니다.** 코드도 `src/Shared` 에 한 군데만 두고 두 프로그램이 같이 씁니다.

| 입력 | 결과 |
|---|---|
| 드래그 | 펜 |
| `Ctrl` + 드래그 | 네모 |
| `Tab` + 드래그 | 동그라미 |
| `Shift` + 드래그 | 직선 |
| `Ctrl+Shift` + 드래그 | 화살표 |
| **마우스 휠** | **선 두께** — 그리는 도중에 굴려도 실시간 반영 |
| `R` `G` `B` `Y` `P` `O` | 색상 (빨강 초록 파랑 노랑 분홍 주황) |
| `E` | 전체 지우기 |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 |
| `F1` | 단축키 안내 보기 |
| `Esc` 또는 `X` | 도구 해제 → 나가기 |
| 오른쪽 클릭 | 그리던 것 취소 → 도구 해제 → 나가기 |

### 도구 — 같은 키를 다시 누르면 펜으로 돌아옴

| 키 | 도구 |
|---|---|
| `H` | 형광펜 |
| `M` | 모자이크 |
| `Shift+M` | 흐리게 |
| `N` | 숫자 마커 — 클릭할 때마다 1, 2, 3… |
| `T` | 텍스트 — 클릭한 자리에 입력, `Enter` 확정 |

> 채점 도장(`Q` `S` `V` `X` `O`)이 있었는데 **수업에서 거의 안 써서 뺐습니다**(26.08.23).
> `O`는 원래 자리였던 주황색으로 돌아갔고, `X`는 나가기 키가 됐습니다. 숫자 마커(`N`)는 그대로입니다.

**형광펜에도 수식키가 그대로 먹습니다.** 굵고 반투명해질 뿐 도형은 같습니다.

| 형광펜 켠 상태 | 결과 |
|---|---|
| 드래그 | 손으로 그은 형광펜 |
| `Shift` + 드래그 | 곧게 그은 형광펜 ← 글줄 강조용 |
| `Ctrl` + 드래그 | 네모 박스 강조 |

모자이크·흐리게는 휠로 세기를, 텍스트는 휠로 글자 크기를 조절합니다.

> 수업 팁 — 모자이크로 답을 가려놓고 설명한 뒤 `Ctrl+Z` 로 걷어내면 그대로 "정답 공개"가 됩니다.

> 전역 캡처 키를 `F1`이 아니라 `Ctrl+F1`로 둔 이유: 맨 `F1`을 전역으로 잡아버리면
> 오버레이 안까지 `F1`이 내려오지 않아 안내 키를 `F2`로 밀어내야 합니다. `F2`는 비워둡니다.

**화살표는 드래그를 시작한 곳이 꼬리, 손을 뗀 곳이 화살촉입니다.**
줌잇은 반대로 시작점에 촉이 생기는데, 그건 따르지 않고 라이트샷 방식으로 통일했습니다.

## 발표 중에 쓸 때 — 화면에 아무것도 안 뜹니다

캔바·파워포인트로 발표하는 중에 쓰려고 만든 규칙입니다. **청중이 같이 보는 화면**이니
부르지 않은 것은 띄우지 않습니다.

- **안내박스는 `F1` 을 눌러야만 뜹니다.** 예전에는 켜자마자 저절로 떴는데, 그게 슬라이드를 덮었습니다.
- **선 두께 표시가 없습니다.** 감으로 맞춥니다. 그은 선이 곧 확인입니다.
- **나가기는 `Esc` 보다 `X` 가 안전합니다.**

마지막 줄이 핵심입니다. 오버레이가 떠 있는 동안에는 어떤 키도 발표 프로그램으로 안 갑니다.
사고는 **오버레이가 이미 닫혔는데 모르고 한 번 더 누를 때** 납니다. 그때 `Esc` 는 캔바로
그대로 들어가 **발표 모드를 끝내버립니다.** `X` 는 캔바가 무시하니 아무 일도 안 일어납니다.

> 캔바가 발표 중에 먹는 글자는 `B` `C` `D` `M` `O` `Q` `U` 와 숫자 `1`~`9` 입니다(26.08.23 확인).
> 철 따라 `S`·`G`·`I`·`F` 같은 글자가 잠깐씩 붙습니다. `X` 는 어느 목록에도 없어서 골랐습니다.

## 모니터 여러 대 — 한 화면만 덮습니다

**두 프로그램 모두** 화면 한 대에서만 동작합니다. 나머지 화면은 그대로 살아 있습니다.

| | 무엇이 달라지나 |
|---|---|
| **ScreenNote** | 확대·주석이 강의 화면만 정지. 옆 모니터의 채팅·자료는 그대로 보임 |
| **ScreenCapture** | 캡처할 때 그 화면만 어두워짐. 넷이 다 어두워지지 않음 |

기본은 둘 다 **마우스가 있는 모니터**입니다. 강의 화면에 마우스를 두고 `Ctrl+2` 를 누르면 거기서 뜹니다.

설정은 **각각 따로** 둡니다 — 트레이 메뉴의 `오버레이 화면`(ScreenNote), `캡처 화면`(ScreenCapture).
주석은 강의 화면에만 달지만 캡처는 화면을 가로질러 잡고 싶을 때가 있기 때문입니다.

> **화면을 가로지르는 캡처가 필요하면** ScreenCapture의 `캡처 화면` 을 **"모든 모니터"** 로 바꾸세요.

고정하고 싶으면 트레이 아이콘 오른쪽 클릭 → 해당 메뉴에서 고릅니다.

| 선택 | 언제 |
|---|---|
| 마우스가 있는 모니터 | 기본. 대개 이걸로 충분합니다 |
| 1번 / 2번 / 3번… 모니터 | 항상 같은 화면에 띄우고 싶을 때 |
| 모든 모니터 | 화면을 가로질러 쓰고 싶을 때. 화면이 하나면 어차피 같습니다 |

번호는 **윈도우 디스플레이 설정에 뜨는 번호와 같습니다.**

모니터가 서넛이면 해상도가 다 같아서 글자만으로는 못 고릅니다. 그래서 **고르고 나면 그 화면
한가운데에 번호가 잠깐 크게 떴다 사라집니다** — 내가 고른 게 저 화면이 맞나 확인용입니다.
아니면 다시 열어서 다른 걸 고르면 됩니다.

고정해 둔 모니터를 뽑으면 자동으로 마우스 쪽으로 돌아갑니다 — 수업 중에 아무것도 안 뜨는 게 제일 나쁘니까요.

## ScreenNote — 수업 중에 쓰는 도구

| 키 | 모드 |
|---|---|
| `Ctrl+1` | 확대 |
| `Ctrl+2` | 화면 주석 |
| `Ctrl+3` | 수업 타이머 |

### Ctrl+1 · 확대

화면이 정지하고 커서를 따라 확대됩니다.

- **마우스 이동** — 확대 지점 이동 (화면 끝까지 다 닿습니다)
- **휠** 또는 **위/아래 방향키** — 배율 100%~800%
- **클릭** — 그 자리에 화면을 고정하고 바로 그리기 시작
- **`Space`** — 다시 마우스를 따라가게
- **`Ctrl`+휠** — 선 두께
- **`Esc`** — 나가기

위의 그리기 단축키가 확대 상태에서도 전부 동작합니다. `T` 텍스트도 됩니다 —
확대 배율에 맞춰 입력되고, 확정하면 화면 좌표에 정확히 얹힙니다.

### Ctrl+2 · 화면 주석

영역을 고르는 단계가 없습니다. 누르는 순간 **화면 전체가 곧바로 칠판**이 됩니다.
위의 그리기 단축키가 전부 그대로 동작합니다.

### Ctrl+3 · 수업 타이머

- **1분 / 3분 / 5분 / 10분** 프리셋, **±30초**
- 시간 표시를 **클릭해서 직접 입력** — `7` 은 7분, `2:30` 은 2분 30초
- `Space` 시작 / 일시정지, `R` 리셋, `Esc` 닫기
- **`F11` 또는 ⛶ 버튼 — 전체화면 전환.** 기본은 작은 창이라 판서하면서 시간을 재고,
  "쉬는 시간 5분" 처럼 화면을 통째로 넘겨줄 때 전체화면으로 바꿉니다
- 드래그로 이동, 휠로 크기 조절
- 10초 남으면 주황색, 0이 되면 빨갛게 깜빡이며 알림음

## ScreenCapture — 자료 만들 때 쓰는 도구

| 키 | 동작 |
|---|---|
| `Ctrl+F1` 또는 `Ctrl+Shift+S` | 캡처 시작 |
| `F3` | 클립보드 이미지를 화면에 고정 |

맨 `F1` 은 Lightshot이 쓰던 자리입니다. 우리는 `Ctrl+F1` 을 쓰므로 Lightshot이 남아 있어도
충돌하지 않고, 지우고 나면 오버레이 안에서 `F1` 안내가 더 확실하게 동작합니다.

### 영역 선택 (라이트샷 방식)

- **드래그** — 영역 선택
- **그냥 클릭** — 커서 아래 창을 통째로 선택
- **`Alt`+드래그** — 선택 영역 이동 (맨 드래그는 그리기로 넘어갔기 때문입니다)
- **테두리 핸들** — 크기 조절
- **`Ctrl+A`** — 화면 전체, **`C`** — 커서 위치의 색상 코드 복사
- 커서 옆 확대경에 좌표와 색상 코드 표시

### 도구

선택하면 라이트샷식 도구 막대가 뜹니다. **버튼으로 골라도 되고, 위의 공용 단축키로 해도 됩니다.**
수식키를 누른 채 드래그하면 도구 막대에서 뭘 골랐든 그 도형이 그려집니다.
아무 키도 안 누른 맨 드래그는 ScreenNote와 똑같이 **펜**입니다.

형광펜·모자이크·흐리게·숫자 마커도 ScreenNote와 같은 키(`H` `M` `Shift+M` `N`)를 씁니다.
도구 막대 버튼이 더 있다는 것만 다릅니다.

### 마무리

| 키 | 동작 |
|---|---|
| `Ctrl+C` 또는 `Enter` | 복사하고 닫기 |
| `Ctrl+S` | **저장 폴더에 바로 저장** — 대화상자 없음 |
| `Ctrl+Alt+S` | 다른 위치를 골라 저장 |
| `Ctrl+D` | 선택 영역을 화면에 고정 |
| `Esc` 또는 `X` | 취소 — 도구 해제 → 선택 해제 → 나가기 |

### 저장 폴더

기본은 **다운로드** 폴더입니다. `Ctrl+S`를 누르면 대화상자 없이 바로 파일이 떨어지고,
어디에 저장됐는지 알림으로 알려줍니다. 파일명은 `Capture_날짜_시각_크기.png` 로 자동입니다.

바꾸려면 **트레이 아이콘 오른쪽 클릭 → "저장 폴더: …"** 를 누르고 폴더를 고르면 됩니다.
메뉴에 현재 폴더 이름이 같이 보여서 열어보지 않아도 확인됩니다.

> `Ctrl+Shift+S` 는 전역 캡처 키라 "다른 이름으로 저장"에 못 씁니다. 그래서 `Ctrl+Alt+S` 입니다.

### 화면 고정 (Snipaste 방식)

`Ctrl+D` 로 고정하면 캡처한 그 자리에 그대로 떠 있습니다. 여러 개 동시에 띄울 수 있습니다.

- **드래그** 이동 (방향키 1px, `Shift`+방향키 10px)
- **휠** 확대/축소, **`Ctrl`+휠** 투명도
- **더블 클릭** 또는 **`Esc`** 닫기
- **오른쪽 클릭** — 복사 / 저장 / 원본 크기 / 불투명도 100% / 닫기

## 소스 구조

```
LectureHelper/
  LectureHelper.sln
  dist/                        배포용 exe 두 개
  src/
    Shared/                    두 프로그램이 같이 쓰는 코드
      Annotations/
        Annotation.cs          도형 모델과 렌더링
        DrawingShortcuts.cs    ★ 도형·도구 단축키 단일 소스
        DrawingSession.cs      도구·색·두께·실행취소 상태 (ScreenNote 두 모드가 공유)
      Native/                  Win32 P/Invoke, 전역 단축키
      Services/                화면 캡처, 모자이크·블러
      Views/AnnotationLayer    주석 렌더링 레이어
      Theme/Controls.xaml      공용 스타일
    ScreenNote/                ZoomWindow · AnnotateWindow · TimerWindow
    ScreenCapture/             CaptureWindow · PinWindow
```

도형 단축키를 바꾸려면 `DrawingShortcuts.cs` 한 곳만 고치면 두 프로그램에 같이 반영됩니다.
한쪽만 바뀌는 일이 생기지 않게 일부러 이렇게 뒀습니다.

화면을 덮는 창(확대·주석·캡처)은 내부를 전부 **물리 픽셀** 좌표로 계산합니다.
창을 `SetWindowPos` 로 대상 영역에 물리 좌표로 붙인 다음 루트에 `1/DPI배율` 변환을 걸어
WPF 단위와 픽셀을 1:1로 맞춥니다. 배율이 다른 모니터를 함께 써도 어긋나지 않습니다.

덮을 영역은 두 프로그램 모두 `OverlayTarget.Resolve()` 가 정합니다. 설정값만 따로 둡니다
(`AppSettings.OverlayMonitor` / `AppSettings.CaptureMonitor`).

```bash
dotnet publish src/ScreenNote/ScreenNote.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=none -o dist
```

포터블본 (런타임 포함, exe 하나당 약 63 MB — 두 앱 다 돌린 뒤 `읽어주세요.txt` 와 함께 zip):

```bash
dotnet publish src/ScreenNote/ScreenNote.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=none -o dist-portable/LectureHelper_Portable
```

`dist-portable/` 은 GitHub 100 MB 제한 때문에 `.gitignore` 에 넣었습니다. 깃허브로 나눌 때는 Releases에 zip을 올리세요.

오류는 `%TEMP%\ScreenNote.log` / `%TEMP%\ScreenCapture.log` 에 남습니다.
